# Bike Tag Wireframes

This document describes the first pass wireframes for the Bike Tag app.

These are planning notes only. They are not production Nuxt code.

## Screens

1. Home
2. Current Tag Detail
3. Submit Tag
4. Map
5. History

## Home Screen

Purpose: Show the current active bike tag and guide the rider to the next action.

Content:

1. Current tag photo
2. Tag title
3. Hint
4. Submit Find button
5. View Map button
6. Recent tags preview

## Current Tag Detail Screen

Purpose: Give the rider more detail about the active tag.

Content:

1. Large active tag photo
2. Tag title
3. Hint
4. General location area
5. Rules reminder
6. Found It button

## Submit Tag Screen

Purpose: Let a rider submit proof that they found the active tag and create the next one.

Content:

1. Proof photo upload
2. New tag photo upload
3. Tag title field
4. Hint field
5. Location selector
6. Submit button

## Map Screen

Purpose: Let riders explore the active tag and previous tags.

Content:

1. Map area
2. Active tag marker
3. Past tag markers
4. Selected tag preview card
5. Filter controls

## History Screen

Purpose: Let riders browse previous tags.

Content:

1. Past tag list
2. Tag thumbnail
3. Tag title
4. General location
5. Solved date
